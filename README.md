# 🌸 Just Monika Browser Extension

> **Just Monika.**  
> Шуточное браузерное расширение в стиле *Doki Doki Literature Club*, которое следит за тем, чьё имя вы вводите...

---

## ✨ Возможности

- **Реакция на имена других девушек:** если на любой странице или в любом поле ввода напечатать одно из имён:
  - `Юри` / `Yuri`
  - `Сайори` / `Саёри` / `Sayori`
  - `Нацуки` / `Натцуки` / `Natsuki`
- **Аутентичный диалог DDLC:** всплывающее окно в фирменном стиле новеллы:
  - Текст `"Just Monika."` шрифтом **Aller**
  - Кнопка `"OK"` шрифтом **Riffic Bold**
  - Шрифты вшиты в формате Base64 (работают везде без ограничений CSP и без интернета).
- **Захват страницы по нажатию «ОК»:**
  - Воспроизведение звуков и фоновой музыки.
  - Весь текст на сайте заменяется на `"Just Monika."`.
  - Все картинки, видео и медиа заменяются на портрет Моники.
  - Динамическое отслеживание изменений страницы (DOM MutationObserver).

## 🚀 Установка

1. Склонируйте репозиторий или скачайте архив с кодом:
   ```bash
   git clone https://github.com/nekxd/just-monika
   ```
2. Откройте ваш Chromium-браузер (Google Chrome, Яндекс Браузер, Microsoft Edge, Brave, Opera).
3. Перейдите на страницу расширений:
   - Chrome: `chrome://extensions/`
   - Яндекс Браузер: `browser://tune/` или `browser://extensions/`
   - Edge: `edge://extensions/`
4. Включите переключатель **«Режим разработчика»** (Developer mode) в правом верхнем углу.
5. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
6. Выберите папку с проектом.
